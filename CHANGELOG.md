All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.2.0] - 2026-08-23

### Added
- Initial project structure with base, dfir, malware, and network profiles
- Docker Compose orchestration with case-scoped workspace mounts
- Python CLI wrapper with case management, shell/exec/enter commands
- GUI forwarding support via X11
- Per-profile image override via .env
- CI workflows for building, linting, and testing
